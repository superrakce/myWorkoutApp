# 身體數據自動計算修正

- BMI、除脂體重、估計靜息代謝在表單內即時預覽，以 readonly 欄位呈現；修改輸入後自動重算。
- 上方卡片顯示今日適用的已儲存量測，未儲存的表單不會寫入紀錄或 Drive。
- 年齡及公式性別參數可獨立儲存，補齊後立即重算已有量測，不必再新增一次體重。
- 估計靜息代謝缺少資料時列出欄位；日期無效或日期推算年齡超出 19～59 時提供原因。
- 實測靜息代謝保留為設備輸入，需填來源；自動估計值不會寫入實測欄位。
- 數字字串轉為數值，依基準日期周年推算年齡，並檢查當日年齡範圍，避免錯誤結果。
- 保持既有資料格式，無需資料遷移。

## 驗證
GitHub Actions 執行既有單元與瀏覽器測試，新增即時重算、唯讀、補齊個人參數、重新整理、雙語、手機寬度、設備實測值與日期邊界案例。使用合成資料，不含使用者量測。

## 必填與日期說明
年齡、年齡填寫日期、公式性別參數、量測日期與時間、身高及體重皆須填寫。新增及編輯量測時採原生必填驗證與儲存檢查；獨立儲存個人參數時檢查年齡、對應日期及性別參數。
年齡填寫日期為所填年齡的對應日期；量測日期與時間為該筆身體數據實際量測時間。介面以中英文說明兩者用途。舊有不完整紀錄保留，編輯儲存時須補齊。

## 合併日期欄位
介面僅保留「量測日期與時間」，同時作為該筆年齡的日期。年齡欄位改稱「量測當日年齡」。
保存時將共用日期寫入既有 profile.ageDate，保留原資料格式與同步相容性。顯示舊資料或切換量測日期時，依原年齡及日期換算，避免把多年前的年齡直接當成今日年齡。
新增單一日期、補登歷史量測、年齡換算、重新載入及編輯不重複紀錄的測試。

## 移除來源及備註輸入
移除身體數據表單的量測來源／設備及備註欄位，實測靜息代謝不再要求填寫設備。舊資料欄位仍保留在儲存、備份及同步資料中，編輯舊量測時保留原值。
