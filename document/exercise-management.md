# 動作管理

新增動作以固定 ID 存入目前工作區的 exerciseLibrary。內建動作以同 ID 覆寫，刪除則保存 deleted 狀態並隱藏於新選擇，不修改原始內建素材。
已儲存課表及實際訓練使用動作快照；編輯與刪除前補齊舊課表所需快照。訓練雷達只使用紀錄快照。
資料包含中英名稱、別名、類型、難度、預設模式、主要／次要部位、必要器材及雙語步驟。圖片沿用專案原創占位圖。
exerciseLibrary 是 Drive 版本圖的一個個別紀錄集合，支援帳號隔離、匯入及衝突選擇；舊備份缺少此集合時仍可讀取。
新增核心測試涵蓋驗證、備份、版本衝突、刪除及帳號隔離；瀏覽器測試涵蓋 CRUD、課表播放、紀錄快照、備份還原、雙語、手機及模擬 Drive 跨裝置同步。
