# FORM — 健身管理第一版

Vue 3 + Vite、Vue Router、Pinia、vue-i18n；個人資料保存在此瀏覽器的 IndexedDB，不需要帳號或後端。

## 執行

建議使用 Node.js 22 LTS 以上（翻譯套件的支援版本）。

```sh
npm ci
npm run dev
```

開啟終端顯示的本機網址，通常為 http://127.0.0.1:5173/。

```sh
npm run test
npm run test:e2e
npm run build
npm run preview
```

瀏覽器測試預設使用已安裝的 Microsoft Edge；其他環境可調整 playwright.config.js 的 channel。建置結果位於 dist/，可放在一般靜態網站主機；使用 hash 路由，不需要伺服器重寫規則。

## 已實作

- 手機底部導覽、桌面側邊欄，檸檬黃、灰色、藍灰與深藍灰主題；英文與繁體中文切換並保存。
- 30 個雙語動作；原創人體部位選擇、搜尋、收藏、類型及難度、器材 OR／全部持有兩種篩選方式。
- 課表新增、編輯、複製、刪除、收藏、順序調整；共同組數、每個動作計次／計時及負重、各階段休息。
- 循環訓練與可編輯 Tabata 模板；開始、暫停、繼續、跳過、中止；時間戳計時、階段檢查點、背景暫停、重載後暫停恢復、Web Locks 單分頁控制。
- 本機音樂、獨立音量、階段提示音及螢幕喚醒的漸進支援；不支援 Web Locks 的瀏覽器不允許控制播放器，避免多分頁重複紀錄。
- 結束摘要確認實際組數、秒數／次數、負重、有效運動時間及自訂 MET；手動補登、修改、刪除紀錄。
- 計畫及紀錄共用六軸雷達圖：每組依不重複主要軸平均分配，排除跳過、有氧、恢復；組數／百分比模式及明細表。組數依各組完成日彙總，場次依開始日。
- 餐別、雙語食物搜尋、自訂食物、克數／份量／本次總熱量、選填營養素、編輯／刪除／複製一餐；每日完整確認及日期區間熱量圖表。
- 身體資料新增／修改／刪除、歷史及體重趨勢、BMI、除脂體重與靜息代謝。過去日期不回填未來量測。
- 完整 JSON 備份、版本及結構驗證、預覽筆數、覆寫前先備份、IndexedDB 交易還原、CSV 檢視匯出與資料清除。

## 第一版內容界線

- 動作圖為自行繪製的原創 SVG 占位圖，**不是正確姿勢示範**；未使用或臨摹 GymVisual 素材。正式靜態姿勢與循環動圖尚待製作及專業審查。動作步驟目前為一般就位提示。
- 初始食物僅 12 筆示例營養值，**尚未匯入及核對約 200 筆食藥署資料**。介面明確標示，可自行依食品包裝輸入。食物跨日期複製、自訂餐別與食物收藏待擴充。
- MET 為使用者輸入的自訂估計，預設 0 表示未估算；**尚未提供經核對的 Compendium 活動代碼庫**。計次、組數及負重不會自行換算熱量。
- 熱量收支是攝取減靜息代謝減運動淨消耗，不是完整 TDEE；7700 kcal/kg 僅為等值，不是體重預測。19–59 歲以外不自動套公式，可輸入有來源的實測靜息值。
- 每日完成確認前，不納入完整日收支；今日標為暫計，不納入過去完整日總和。無雲端、PWA 安裝或鎖屏持續計時。
- 目前自動化驗證以本機 Edge 為主；Safari、iOS、Android 實機、20 分鐘計時誤差及大量資料效能仍需後續驗收。

## 結構

`src/data` 保存版本化初始內容；`services/domain.js` 是共用純函式；`repositories` 封裝 IndexedDB；`stores` 管理跨頁狀態；`composables/usePlayer.js` 管理播放器生命週期；`components` 提供表單、圖表與卡片；`views` 組合各功能頁。

完整需求保留於 `document/rfq.txt`；原始研究連結保留於 `document/references/`。GitHub Actions 與 Pages 部署方式見 `document/ci-deployment.md`。
